# 期货策略回测台

用历史行情检验一套买卖规则，看它过去能不能赚钱，不花一分真钱。

## 怎么用

把 `index.html` 下载到电脑上，双击用浏览器（Chrome / Edge）打开就行，不需要安装任何软件。

## 功能

- 4 个经典策略：双均线交叉、通道突破（海龟法则）、布林带回归、MACD 金叉死叉
- 我的策略：RSI 超卖分批加仓（RSI<20 开 1 手，继续走低依次加 1、2、4 手，RSI>80 全平，可设止损）
- 日线 / 周线 / 月线，RSI、MACD 副图
- 联网下载新浪财经主力连续日线，或导入自己的 CSV
- 30 个活跃品种一键批量回测
- 风控：高波动自动降仓，并自动给出“降仓 / 不降仓”对比
- 交易明细导出 CSV

## 回测规则

每根 K 线收盘后判断信号，下一根 K 线开盘成交，扣除滑点和手续费，避免“偷看未来”。

## 免责声明

回测结果只代表过去，不构成任何投资建议。合约参数为常见近似值，实际以交易所和期货公司为准。
